- A pull request records its changelog entry as its own file,
  `changelog.d/<issue>.<category>.md`, so that open pull requests no longer conflict
  on the same lines of `CHANGELOG.md`; a tested script validates the fragments and the
  release commit assembles them into `[Unreleased]`. The unchanged-synchronization
  exemption also covers the merge of `main` into a short-lived branch when its diff
  against the release branch is empty (#374).
