# K-Risk-Engines traffic history

Daily aggregate repository analytics are collected on this branch. The first snapshots were recorded on 20–21 October 2026; collection is no longer pending initial setup. The branch contains daily snapshots, referrer/path summaries and badge endpoint data under `data/`.

See [setup, data definitions and limitations](https://github.com/danielep71/K-Risk-Engines/blob/main/docs/TRAFFIC.md). Current collection status should be checked in the latest workflow run and the dated CSV records; this README does not guarantee subsequent daily runs have succeeded.
