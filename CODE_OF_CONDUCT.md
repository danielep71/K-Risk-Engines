# 🤝 Code of conduct

This repository adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the
repository's issues, pull requests, reviews, discussions and commit history.

In short: be respectful and constructive, assume good faith, keep feedback
about the work, and never harass, demean or publish another person's private
information.

## 📣 Reporting

- For content on GitHub, such as a comment, an issue or a pull request, use
  GitHub's **Report content** option on that item, or report the account to
  GitHub.
- For anything else, use the contact details on the
  [repository owner's GitHub profile](https://github.com/danielep71). Do not
  describe the incident in a public issue.

Every report is read and the reporter's identity is kept private. Responses
follow the Contributor Covenant's enforcement guidelines, from a private
correction to a permanent ban from the repository.

Security vulnerabilities are not conduct reports: follow the
[security policy](SECURITY.md).
